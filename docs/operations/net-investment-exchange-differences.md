# Net-investment exchange differences

Native foreign-currency revaluation remains in profit or loss in each legal entity’s standalone books. For a qualifying long-term, non-trade monetary loan, a controller can prepare a period-specific net-investment FX assessment from **Company Settings → Setup → Subsidiary ownership interests**. The existing Accounting changes screen and Flows workflow record the evidence, independent approval and application.

Enable Multi-Subsidiary and Multi-Currency on Company Settings → Features. Configure a dedicated monetary due-from / due-to intercompany pair, an OCI equity reserve, the native unrealized FX gain-or-loss account and an elimination entity. The command requires `close.run` and authorization for every entity involved. The supported scope is a wholly owned, fully consolidated foreign operation, financed by its parent or another effective wholly owned subsidiary of that parent. A non-controlling interest requires a separate attributable OCI assessment and is refused by this command rather than allocating it by assumption.

Select the primary posting book, an open assessment date and the actual native FX monetary lines for that period. Document the signed financing terms and treasury evidence that settlement is neither planned nor likely in the foreseeable future. Trade AR and AP do not qualify. Each account must identify one intercompany counterparty and the audited FX exposure must identify one currency. The source line’s actual signed exchange difference is translated at the same consolidated average rate as its profit-or-loss contribution, then offset against the OCI reserve. Source journals remain intact. A source line can have only one live attribution, including when a request is retried.

This is a period-specific review, not a permanent automatic election. At later closes, review current FX adjustments and opening reversal mirrors together with the continuing loan qualification. The service does not automatically mirror the OCI reserve into the next period or infer that loan repayment constitutes disposal. IAS 21 treats qualifying loan exchange differences differently in separate and consolidated statements; the IFRS Interpretations Committee’s September 2010 discussion did not establish a universal repayment-without-ownership-change recycling rule. A controller must establish the applicable disposal treatment from the actual ownership and contractual event.

The adjustment carries ownership lineage into the native loss-of-control workflow. On a genuine disposal, that workflow validates the attributable posted OCI balance before releasing it to the selected destination. Do not also reverse the standalone loan FX. For an erroneous assessment, choose **Propose reversal** on its Accounting changes record, obtain independent approval and apply the correction in an open period. A correction appends a reversing journal and releases source attribution for a new assessment; it never overwrites historical evidence. Correct an approved loss-of-control event first if it already relied on that reserve. Historical assessment corrections remain available when their creation features are disabled.

References: IAS 21 paragraphs 15, 15A, 32 and 48; [IFRIC repayment discussion, September 2010](https://www.ifrs.org/content/dam/ifrs/supporting-implementation/agenda-decisions/2010/ias-21-repayments-of-investments-and-foreign-currency-translation-reserve-september-2010.pdf).
