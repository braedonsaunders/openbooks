# Analysis reports

Distilled from the extraction (see ../extraction/) by deep-reads of the SDF
XML. These are the working spec for what openbooks must model natively.

- `customizations.md` — every custom field/record/list/workflow/role Rassaun
  bolted onto NetSuite, grouped by business domain, with promote/registry/drop
  recommendations (reflected in ../schema/DESIGN.md).
- `reporting.md` — the 247 saved searches + 25 financial layouts + workbooks
  digested into reporting-engine requirements: dimensions the business slices
  by, must-have report types, worklist/scheduling patterns.
